# デザイン

Shelfy の見た目の決まりを 1 か所にまとめる。
画面を変えるときは、先にこの文書を読み、足りなければこの文書を直してから画面を直す。

状態：**確定**

## 1. 方針

Windows 11 の Fluent に揃え、その中で階層、密度、状態の見え方を磨く。
エクスプローラーの隣に置いて違和感がないことを優先し、Shelfy らしさはアクセントの琥珀色とアプリアイコンに集める。

配布サイズを最優先する設計（[ARCHITECTURE.md](ARCHITECTURE.md) 第 15 節）に従い、フォントもアイコンも同梱しない。
Windows 11 に標準搭載されたものだけで組む。

検索と棚のブラウズは同等に扱う。
ホットキーで呼んで打って Enter で開く使い方と、棚を眺めてダブルクリックで開く使い方の、どちらも主役である。

## 2. 色

色は `src/lib/styles/tokens.css` にトークンとして置き、部品はトークン名だけを参照する。
値は OKLCH で書く。
灰色には琥珀の色相（65〜75）をわずかに混ぜ、純白と純黒は使わない。

| トークン          | 役割                                           | 明るいテーマ            | 暗いテーマ            |
| ----------------- | ---------------------------------------------- | ----------------------- | --------------------- |
| `--bg-opaque`     | Mica が効かないときのウィンドウ背景            | `oklch(96.4% 0.004 75)` | `oklch(19% 0.004 75)` |
| `--layer-solid`   | ペイン、ダイアログ、メニュー                   | `oklch(98.8% 0.003 75)` | `oklch(24% 0.005 75)` |
| `--fg`            | 本文                                           | `oklch(21% 0.008 65)`   | `oklch(95% 0.003 75)` |
| `--fg-sec`        | パス、日付、補足、プレースホルダ               | `oklch(47% 0.008 65)`   | `oklch(76% 0.006 75)` |
| `--stroke`        | ペインの境界、区切り線                         | `oklch(89% 0.005 75)`   | `oklch(32% 0.005 75)` |
| `--stroke-strong` | 入力欄の下辺                                   | `oklch(62% 0.006 65)`   | `oklch(58% 0.006 75)` |
| `--accent`        | 主ボタンの塗り                                 | `oklch(76% 0.15 72)`    | `oklch(80% 0.14 76)`  |
| `--accent-ink`    | 主ボタンの文字                                 | `oklch(22% 0.03 65)`    | `oklch(20% 0.03 65)`  |
| `--accent-line`   | 選択中の印、入力のフォーカス線、ドロップ先の線 | `oklch(60% 0.13 62)`    | `oklch(80% 0.14 76)`  |
| `--accent-text`   | 検索結果に添える棚の名前                       | `oklch(50% 0.11 62)`    | `oklch(82% 0.12 78)`  |
| `--warn`          | 参照先が見つからない                           | `oklch(55% 0.17 35)`    | `oklch(74% 0.13 45)`  |
| `--focus`         | キーボードのフォーカスリング                   | `--fg` と同じ           | `--fg` と同じ         |

重なりの色は、トークンに透明度を掛けて作る。
透明度そのものを色の定義にはしない。

| トークン     | 作り方                                                    |
| ------------ | --------------------------------------------------------- |
| `--layer`    | `--layer-solid` を 72%（暗いテーマは 55%）。Mica を透かす |
| `--hover`    | `--fg` を 5%（暗いテーマは 7%）                           |
| `--selected` | `--accent` を 16%（暗いテーマは 20%）                     |

明るいテーマで線に使う琥珀は、塗りの琥珀より濃くしている。
塗りと同じ明るさの線は、明るい背景に対するコントラストが 2:1 程度しかなく、状態を示す印に求められる 3:1 に届かないためである。

`--warn` は赤寄りにして、アクセントの琥珀と見分けられるようにする。
色だけに頼らず、必ず警告のアイコンと文言を添える。

## 3. 文字

| 役割     | 書体                                     | 大きさと太さ | 使う場所                         |
| -------- | ---------------------------------------- | ------------ | -------------------------------- |
| 見出し   | Segoe UI Variable Display → Yu Gothic UI | 20px、600    | 一覧の見出し（棚の名前、検索語） |
| 小見出し | Segoe UI Variable Text → Yu Gothic UI    | 15px、600    | ダイアログの題、空状態の一文     |
| 本文     | Segoe UI Variable Text → Yu Gothic UI    | 13px、400    | 項目名、棚の名前、ボタン         |
| 補足     | Segoe UI Variable Text → Yu Gothic UI    | 11px、400    | パス、日付、ステータス、ラベル   |

見出しの書体を分けるのは一覧の見出しだけにし、画面の重心をそこに置く。
斜体は使わない。
日付と件数には `font-variant-numeric: tabular-nums` を指定し、桁を揃える。

## 4. 寸法

| 要素                   | 値                                 |
| ---------------------- | ---------------------------------- |
| タイトルバー           | 高さ 40px                          |
| ボタン、入力欄、棚の行 | 高さ 32px                          |
| 項目の行               | 44px、メモがあれば 60px の 2 種類  |
| 棚のペイン             | 幅 220px                           |
| ペインの間隔と外周     | 8px                                |
| 角丸                   | 小要素 4px、ペインとダイアログ 8px |
| 余白の刻み             | 4px の倍数                         |

項目の行の高さを変えるときは、仮想スクロールの定数（[ItemList.svelte](../src/lib/components/ItemList.svelte) の `ROW_PLAIN` と `ROW_WITH_MEMO`）も同時に変える。
行の位置を高さの累積和で計算しているため、ずれると表示が崩れる。

操作の高さは 32px とする。
マウスとキーボードで使うデスクトップアプリであり、Fluent の標準の高さに揃える。

## 5. 状態

操作できる部品は、次の状態をすべて持つ。

| 状態       | 見え方                                                                                  |
| ---------- | --------------------------------------------------------------------------------------- |
| 通常       | 背景なし、または `--layer`                                                              |
| ホバー     | 背景を `--hover` に                                                                     |
| フォーカス | `--focus` の 2px の輪郭線を 1px 離して描く。`:focus-visible` のときだけ出し、動かさない |
| 押下       | 背景を `--hover` の 2 倍の濃さに                                                        |
| 無効       | 不透明度 0.45。理由が伝わる場所ではツールチップで理由を示す                             |
| 選択中     | 背景を `--selected` にし、棚の行は左端に `--accent-line` の縦 3×16px の印を置く         |

`outline: none` は、代わりのフォーカス表示を用意したときだけ書く。
入力欄のフォーカスは、下辺の線を `box-shadow` で 2px にして示す。
枠線の太さを変えると、フォーカスのたびに中身が 1px ずれるためである。

## 6. 動き

100〜150ms のフェードだけを使う。
ランチャーは呼んだ瞬間に使えることが価値であり、動きで待たせるわけにはいかない。

| トークン     | 値                              |
| ------------ | ------------------------------- |
| `--dur-fast` | 120ms                           |
| `--ease-out` | `cubic-bezier(0.16, 1, 0.3, 1)` |

`transform` と `opacity` 以外は動かさない。
`prefers-reduced-motion: reduce` では、フェードも止める。

## 7. レイアウト

```text
┌ [棚] Shelfy ── [ 検索 ] ──────────────── ⋯  — ┐
├──────────────┬────────────────────────────────┤
│ 棚        ＋ │ 仕事                  ＋ URL   │
│ ▌ 仕事       │ 項目の一覧                     │
│   ツール     │                                │
│ ──────────── │                                │
│ 最近使ったもの│                                │
│ 見つからない項目│                              │
├──────────────┴────────────────────────────────┤
│ ステータス                                     │
└────────────────────────────────────────────────┘
```

操作の置き場所は、その操作が何に効くかで決める。

| 操作                             | 置き場所                               |
| -------------------------------- | -------------------------------------- |
| 棚を作る                         | 棚のペインの見出しの「＋」、`Ctrl+N`   |
| この中に棚を作る                 | 棚の右クリックメニュー                 |
| 最近使ったもの、見つからない項目 | 棚の一覧の下にある表示切り替えの行     |
| URL を追加する                   | 一覧の見出しの右（開いている棚に入る） |
| 取り込む、書き出す、設定         | タイトルバーの「⋯」メニュー            |

## 8. 空状態とドロップ

一覧が空のときは、ステータスバーの 1 行で済ませず、一覧の中に理由と次の操作を出す。

| 場面                    | 一文                               | 操作                       |
| ----------------------- | ---------------------------------- | -------------------------- |
| 棚が 1 つもない         | 棚がまだありません                 | 棚を作る（`Ctrl+N`）       |
| 開いている棚が空        | この棚は空です                     | ドロップの案内、URL を追加 |
| 検索で 0 件             | 「〇〇」に一致する項目はありません | 絞り込みの書き方を示す     |
| 見つからない項目が 0 件 | 見つからない項目はありません       | なし                       |
| 最近使ったものが 0 件   | まだ開いた項目がありません         | なし                       |

エクスプローラーからドラッグしている間は、一覧に `--accent-line` の破線の枠と、追加先の棚の名前を出す。
Tauri のドラッグの通知（`enter`、`over`、`leave`、`drop`）で出し入れする。

## 9. 取り込み

取り込み方は、ダイアログの中で「足す」と「置き換える」から選ばせ、既定は「足す」にする。
「置き換える」には、いまのデータが消えて戻せないことを警告の色とアイコンで添える。

ボタンは「やめる」と「取り込む」の 2 つにする。
Esc と背景のクリックは「やめる」と同じにし、何も取り込まない。

## 10. アイコン

### アプリアイコン

棚板 1 枚に背表紙 3 冊を置く。
右の 1 冊を傾けて、棒グラフではなく本棚に見えるようにする。

| ファイル                        | 用途                                             |
| ------------------------------- | ------------------------------------------------ |
| `src-tauri/icons/source.svg`    | 原本（48 グリッド）。20px 以上はここから書き出す |
| `src-tauri/icons/source-16.svg` | 16px 用。画素に合わせ、背表紙の帯を省く          |

書き出しの手順は [DEVELOPMENT.md](DEVELOPMENT.md) 第 2.3 節にある。

| 色        | 値                    | 使う場所     |
| --------- | --------------------- | ------------ |
| `#D37814` | `oklch(66% 0.15 60)`  | 左の本、帯   |
| `#F2B036` | `oklch(80% 0.15 78)`  | 中央の本     |
| `#F5DC98` | `oklch(90% 0.09 90)`  | 傾いた本、帯 |
| `#574336` | `oklch(40% 0.035 55)` | 棚板         |

アイコンの色はテーマで変えない。
ラスタライザが OKLCH を読めないことがあるため、SVG には 16 進で書く。

### トレイアイコン

形は 16px 版と同じで、単色にする。
タスクバーのテーマ（レジストリの `SystemUsesLightTheme`）を見て切り替える。
アプリのテーマ（`AppsUseLightTheme`）とは別に設定できるため、ウィンドウのテーマでは判断しない。

| ファイル                            | タスクバー |
| ----------------------------------- | ---------- |
| `src-tauri/icons/tray-on-light.svg` | 明るい     |
| `src-tauri/icons/tray-on-dark.svg`  | 暗い       |

### 画面内のアイコン

Segoe Fluent Icons のグリフを文字として描く（Windows 10 では Segoe MDL2 Assets）。
大きさは、棚と項目の種別が 16px、ボタンとメニューが 14px の 2 段にする。
色は `--fg-sec` にし、警告だけ `--warn` にする。

## 11. 変えないもの

- Mica と、それが効かないときの不透明な背景
- 明暗を OS の設定に追従させること
- キーボードショートカットと、その割り当て
- 右クリックメニューの項目と並び
